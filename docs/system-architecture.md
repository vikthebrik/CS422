# MCC Calendar Hub — System Architecture

> **Domains:** `uomcc.org` (frontend) · `api.uomcc.org` (backend)  
> **Stack:** Vercel + Render + Supabase + Resend + Cloudflare

## ② Vercel — Static SPA Hosting

**URL:** `uomcc.org`  
**Build:** `cd frontend && pnpm install && pnpm build`  
**Env var:** `VITE_API_BASE_URL` (points to `https://api.uomcc.org`)

### React 18 SPA

| Component / Hook | Purpose |
|-----------------|---------|
| `AppContext` | Global state: `events`, `clubs`, `auth`, `filters` |
| `useClubs` | Fetches `/clubs`, assigns colors from palette |
| `useEvents` | Fetches `/events` after clubs load, maps fields, builds `typeIdMap` |
| `Dashboard` | Calendar grid + list views |
| `FilterSidebar` | Advanced mode: per-club event type filters + search |
| `EventPage` | Detail view, edit modal, collaborators, auto-sync pause banner |
| `ClubPage` | Club profile, upcoming events, Our Team section |
| `ClubManagement` | Root admin portal (add/delete clubs, event types, account requests) |
| `Collab` | Pending / accepted / past collaborative events |
| `About` | Block-based CMS page (public view; root admin can edit inline) |

**Auth pages (5 routes):** `/forgot-password` → `/reset-password` · `/request-account` · `/change-password` · `/confirm-email`

**Auth notes:**
- JWT stored in `localStorage` under key `mcc_auth_token`
- No Supabase client on the frontend — all auth proxied through Express backend
- Sign-out clears context + `localStorage`

## ③ Render — Express API

**URL:** `api.uomcc.org:10000`  
**Entry:** `src/index.ts`  
**Build:** `npm install && npm run build` → `node dist/index.js`  
**Body limit:** 8 MB · **CORS:** `ALLOWED_ORIGINS` env var

### Public Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/clubs` | All clubs with `social_links`, `metadata_tags` (jsonb) |
| `GET` | `/events` | All events with `collaborators[]`, `manually_edited`, RSVP fields |
| `GET` | `/events/ics?filters=clubId:typeId,...` | ICS calendar file (typeId optional) |
| `GET` | `/event-types` | `{ id, name }[]` |
| `GET` | `/site-settings/:key` | Public jsonb value |
| `GET` | `/` | HTML status dashboard |
| `GET` | `/status` | JSON status (sync history, cache, log tail) |

### Auth Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/auth/login` | `{ email, password }` → `{ token, user }` |
| `GET` | `/auth/me` | Validate Bearer token |
| `POST` | `/auth/forgot-password` | Trigger password reset email via Resend |
| `POST` | `/auth/reset-password` | Validate `token_hash`, update password |
| `POST` | `/auth/change-password` | Verify current password, update (requires auth) |
| `POST` | `/auth/change-email` | HMAC-signed confirmation email (24h expiry) |
| `POST` | `/auth/confirm-email` | Validate HMAC token, update email |
| `POST` | `/auth/request-account` | Insert into `account_requests` |

### Mutations (Bearer token required)

| Method | Path | Notes |
|--------|------|-------|
| `PATCH` | `/events/:id` | Sets `manually_edited = true` for content changes; `{ resumeSync: true }` clears it |
| `DELETE` | `/events/:id` | Root: any; club_admin: own club only |
| `PATCH` | `/clubs/:id` | Merges `social_links` jsonb (does not overwrite) |
| `POST` | `/clubs/:id/logo` | Base64 → `club-logos` bucket → `logo_url` |
| `POST/DELETE` | `/events/:id/collaborators[/:clubId]` | Add / remove collaborating club |
| `PATCH` | `/collab/:id { status }` | Accept or reject collaboration |
| `DELETE` | `/collab/:id` | Delete collaboration record |
| `POST/PATCH/DELETE` | `/clubs/:id/members[/:memberId]` | Team member CRUD |
| `POST` | `/clubs/:id/members/:memberId/photo` | Upload to `member-photos` (max 300px, WebP) |

### Admin Endpoints (requireRoot)

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/admin/users` | All club_admin accounts with `raw_password` |
| `POST` | `/admin/passwords/:userId` | Force-set password |
| `PATCH` | `/admin/users/:userId/email` | Immediate email update |
| `GET/POST` | `/admin/requests[/:id/approve]` | View / approve account requests |
| `POST/DELETE` | `/clubs[/:id]` | Create / delete club (cascades events + user_roles) |
| `POST/PATCH/DELETE` | `/event-types[/:id]` | Event type CRUD |
| `PUT` | `/site-settings/:key` | Upsert jsonb (About page CMS) |
| `POST` | `/site-settings/upload` | Media → `mcc-public-assets` bucket |

### Internal

| Method | Path | Auth |
|--------|------|------|
| `POST` | `/internal/cache/clear` | Header `x-sync-secret` (no JWT) |
| `POST` | `/admin/sync` | Header `x-sync-secret` — manual ICS sync trigger |

### Internal Modules

| Module | Purpose |
|--------|---------|
| **Cache** (`src/cache.ts`) | In-memory TTL store. Keys: `events:all`, `clubs:all`, `event-types:all`. TTL: `CACHE_TTL_SECONDS` |
| **Logger** (`src/logger.ts`) | Ring buffer (200 entries). Levels: `info`, `success`, `warn`, `error`, `cron`, `auth`, `cache` |
| **Dashboard** | Status page with sync history, log tail, cache info |

### Roles

| DB Role | Frontend Role | Scope |
|---------|--------------|-------|
| `root` | `admin` | All clubs, all events, full admin |
| `club_admin` | `club_officer` | Own org only |

## ③b ICS Sync Worker

**Files:** `src/cron.ts` · `src/scripts/sync_all.ts` · `src/scripts/populate_supabase.ts`  
**Schedule:** `SYNC_CRON_SCHEDULE` env var (default: `*/14 * * * *`)

### Per-club sync flow

1. **HTTP GET** `<clubs.ics_source_url>` — parse `.ics` feed
2. **Classify event type** by title/description tags:
   - `[E]`/`[Event]` → Events · `[M]`/`[Meeting]` or keyword `"meeting"` → Meetings
   - `[OH]`/`[Office Hours]` or keyword `"office hours"` → Office Hours · `[O]`/`[Other]` → Other
   - `[T]`/`[Ticket]` / keywords `tickets`, `rsvp`, `register` → sets `requires_rsvp = true`
3. **Strip Microsoft Teams boilerplate** from description; preserve join URL as `[Teams: https://...]`
4. **Parse attendees** `PARTSTAT`: `ACCEPTED` → collaboration `status = accepted`; others → `pending`
5. **Upsert collaborations** with `ignoreDuplicates: true` — user-set accept/reject never overwritten
6. **`manually_edited` check:** if `true`, only update `last_updated` — all other fields frozen
7. **Prune** events in DB whose UID is not in current feed
8. **Clear cache:** `POST /internal/cache/clear` (x-sync-secret)

**Club lookup:** by `ics_source_url` (not name) — admin deletions are permanent

## ④ Supabase

### PostgreSQL Schema

| Table | Key Columns |
|-------|-------------|
| `events` | `uid`, `title`, `description`, `location`, `start_time`, `end_time`, `type_id`, `club_id`, `manually_edited` (bool, m009), `requires_rsvp`, `rsvp_link`, `rsvp_note` (m013), `last_updated` |
| `clubs` | `name`, `org_type` (`union`\|`department`), `ics_source_url`, `logo_url`, `social_links` (jsonb), `metadata_tags` (jsonb) |
| `collaborations` | `event_id`, `club_id`, `role`, `status` (`pending`\|`accepted`\|`rejected`) |
| `user_roles` | `user_id`, `email`, `role` (`root`\|`club_admin`), `club_id`, `raw_password` (m010) |
| `event_types` | `id`, `name` |
| `account_requests` | `club_name`, `contact_email`, `message`, `status` |
| `site_settings` | `key`, `value` (jsonb) — `about-page` key stores `Block[]` |
| `club_members` | `name`, `title`, `section` (`exec`\|`board`\|`intern`), `email`, `photo_url`, `sort_order`, `club_id` (m014) |

**Migrations:** `001–014` in `server/src/db/migrations/`

### Supabase Auth (admin API only — backend only)

| Operation | Use case |
|-----------|---------|
| `admin.generateLink({ type: 'recovery' })` | Password reset — generates `hashed_token` for PKCE bypass |
| `admin.verifyOtp({ token_hash, type: 'recovery' })` | Validates reset token |
| `admin.createUser()` | Seeding + account approval |
| `admin.updateUserById()` | Password / email changes |

### Storage Buckets

| Bucket | Upload Endpoint | Notes |
|--------|----------------|-------|
| `club-logos` | `POST /clubs/:id/logo` | Base64 → public URL; root or own club_admin |
| `member-photos` | `POST /clubs/:id/members/:memberId/photo` | Max 300px, WebP |
| `mcc-public-assets` | `POST /site-settings/upload` | About page images/media |

## ⑤ Resend — Email Delivery

**SDK:** Resend HTTP API · **Env vars:** `RESEND_API_KEY`, `SMTP_FROM`  
**Why not SMTP:** Render blocks outbound ports 25/465/587. Resend uses HTTP/443.  
**Pattern:** Fire-and-forget — Express responds immediately; email sent async.

| Email type | Trigger | Content |
|-----------|---------|---------|
| Password reset | `POST /auth/forgot-password` | Branded HTML, MCC green `#004F35`, `token_hash` link |
| Account approval | `POST /admin/requests/:id/approve` | Login credentials to club contact email |
| Email change | `POST /auth/change-email` | HMAC-signed confirmation link, 24h expiry |

## Key Data Flows

### Public calendar view
```
Browser → Cloudflare → Vercel → React SPA
  useClubs  → GET /clubs  → Express → [Cache or Supabase PG]
  useEvents → GET /events → Express → [Cache or Supabase PG]
```

### Authenticated event edit
```
Club officer edits event → PATCH /events/:id Bearer JWT
  → Express validates JWT → checks club scope
  → Supabase PG: SET manually_edited = true
  → Cache cleared (events:all)
  → React context: updateEvent({ manuallyEdited: true })
  → Amber "Auto-sync paused" banner shown on EventPage
```

### ICS sync cycle (every 14 min)
```
node-cron → sync_all.ts
  for each club with ics_source_url:
    → HTTP GET <ics_source_url>
    → populate_supabase.ts: classify → upsert → prune
    → skip all fields if manually_edited = true (except last_updated)
  → POST /internal/cache/clear (x-sync-secret)
```

### Password reset
```
POST /auth/forgot-password
  → admin.generateLink({ type: 'recovery' }) → token_hash
  → Resend: branded email with /reset-password?token_hash=...
POST /auth/reset-password { token_hash, newPassword }
  → admin.verifyOtp() → admin.updateUserById()
  → user_roles.raw_password updated
```
